    About this page

    What was checked. Every outcome on this page was run on Linux (Ubuntu 26.04, Python 3.14, 9 November 2026): the four ways of stopping report.py, with their exit statuses and what the log contained; the write calls with strace; and the dirty pages in /proc/meminfo after writing and closing 200 MiB.

    The buffer. Python 3.14 uses a buffer of 128 KiB for files, as in the lab. Output to a terminal is written line by line; output to a file or a pipe waits in the buffer.

    Writeback. On this machine the kernel writes a dirty page back once it has been dirty for 30 seconds (vm.dirty_expire_centisecs = 3000) and checks every 5 seconds; other machines use other settings. A disk can also keep data in a cache of its own; os.fsync asks it to store the data too.
